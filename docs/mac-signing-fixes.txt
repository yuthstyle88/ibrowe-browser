Mac Signing & Packaging Fixes for iBrowe Browser
==================================================
Applied to make iBrowe Browser build, sign, notarize, and launch successfully on macOS 26.

ROOT CAUSES FIXED
-----------------
1. PKG signing failed — no "Developer ID Installer" cert available
2. Privileged helper signing path was wrong (ibrowe regex didn't match actual binary name)
3. SMPrivilegedExecutables mismatch — helper's SMAuthorizedClients didn't include com.ibrowe.Browser (POSIX 163)
4. BraveUpdater.app signed by Brave's team ID (KL8N8XSYF4), incompatible with library-validation on our team (D8FP7GS222)
5. com.apple.developer.associated-domains.applinks.read-write entitlement not in provisioning profile — AMFI kills process on macOS 26 (POSIX 163 / exit 137)
6. subprocess missing import in signing.py caused validate_app warning


FILES MODIFIED
--------------

SOURCE FILES (persist across rebuilds):

1. src/brave/script/signing_helper.py
   - Fixed regex in BraveModifyPartsForSigning() to match both com.brave.Browser
     and com.ibrowe.Browser variants for the privileged helper path
   - Old: channel_re = 'com.brave.Browser(.*).UpdaterPrivilegedHelper'
   - New: channel_re = r'com\.(brave|ibrowe)\.Browser(.*)?\.'UpdaterPrivilegedHelper'
          replacement = r'com.brave.Browser.UpdaterPrivilegedHelper'

2. src/chrome/installer/mac/signing/parts.py
   - Reverted cleanup code that removed the privileged helper binary
   - Made privileged helper signing skip gracefully when binary is absent (WARN instead of error)

3. src/chrome/installer/mac/signing/pipeline.py
   - Added import subprocess
   - Added _identity_in_keychain() helper function
   - Made productbuild --sign conditional on Developer ID Installer cert being in keychain
   - Made PKG notarization conditional on PKG being signed
   - Removed assert dist_config.installer_identity

4. src/chrome/installer/mac/signing/signing.py
   - Added: import subprocess

5. src/chrome/app/app-entitlements-chrome.plist
   - Removed: com.apple.developer.associated-domains.applinks.read-write
   - Reason: Not in provisioning profile; AMFI kills app on macOS 26 when entitlements
     don't match the embedded provisioning profile

6. src/out/Release_arm64/args.gn
   - Added: enable_updater=false
   - Reason: Disables the updater so SMPrivilegedExecutables is not added to Info.plist
     and BraveUpdater.app is not included in the bundle

7. src/ibrowe/src/patches/script-signing_helper.py.patch
   - Updated to reflect new regex in signing_helper.py

8. src/brave/patches/chrome-installer-mac-signing-pipeline.py.patch
   - Updated to reflect all pipeline.py changes

9. src/brave/patches/chrome-installer-mac-signing-parts.py.patch
